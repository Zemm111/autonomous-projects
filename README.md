# Autonomous Projects — Website

Marketing site for Autonomous Projects, an agentic software agency.

## Quick Start

```bash
npm install
npm run dev
```

## Build & Export

```bash
npm run build    # Outputs static site to out/
npm run serve    # Serve locally
```

## Tech Stack

- Next.js 14 (App Router, static export)
- TypeScript
- Tailwind CSS
- Framer Motion

## Deploy

Push to GitHub → import in Vercel. Zero config needed.
